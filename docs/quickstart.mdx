## Installation

With Malbox, you have two choices about how you want to install the platform.
You can either go through [Automatic](/installation/automatic) or [Manual](/installation/manual) installation.

If you are not a power-user or if your installation environment is pretty common, we highly suggest going through Automatic installation.
